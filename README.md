# Plot Structure Analyzer

小説・漫画のプロットをAIで構造分析し、「起・承・転・結」のタイムラインとして静かに描き出すミニマルなシングルページアプリケーション（SPA）です。

## 主な特徴

- **極限まで削ぎ落としたプロット入力画面**: 余計な装飾を排し、テキストエリアと「分析する」ボタンのみで構成。
- **テキストが主役のタイムライン表示**: 分析完了直後は、各フェーズ名とあらすじのテキストのみを横書きでスッキリと表示。
- **タップ駆動型のアコーディオンUI**: 任意のフェーズをタップしたときだけ、AIによる詳細フィードバック（パワーバランスの矛盾点・改善案・感情曲線）および下部ナビゲーションメニューが滑らかに出現します。

## セットアップと起動

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開いてください。

## AI連携（オプション）

デフォルトではキー設定不要のローカル構造解析エンジンが動作するため、そのまま即座にお試しいただけます。  
実際の Gemini API（`gemini-3.8-flash`）による構造化JSON分析を使用する場合は、プロジェクトルートに `.env.local` を作成してAPIキーを設定してください。

```env
GEMINI_API_KEY=your_api_key_here
```
